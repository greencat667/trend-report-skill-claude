# Contributing to Trend Report

Thanks for your interest in improving this skill.

**This repo is not actively maintained.** It was published as a one-time release, not something
I'm committed to reviewing or updating on an ongoing basis. Issues and PRs may sit unanswered for
a long time, or indefinitely. If you need changes, forking is likely faster than waiting on a
response here.

## What's most useful

- A refinement to a section prompt in `prompts/` (structure, word budget, style rules)
- A fix to the drafting-order dependencies in `SKILL.md`
- An improvement to `references/word-export.md`'s export quality checks
- A second worked example in `examples/`, clearly fictional or genuinely your own

## How to contribute

1. Fork the repository
2. Create a branch (`git checkout -b improvement/your-change`)
3. Make your changes
4. Open a pull request with a clear description of what you changed and why

## What to avoid

- Real internal reports, project files, or organisational content as examples — keep worked
  examples fictional or clearly your own to publish
- Re-adding organisation-specific defaults (a default org name, a default set of strategic
  pillars, a specific national/international split) — every organisation using this skill has
  different ones; the skill should always ask, never assume
- Committing a real branded template into `assets/report-template.docx` — it should stay a
  blank, generic reference template

## Questions?

Open an issue if you like, but see the note above — don't expect a quick reply.
