# Learning Priorities

> **Section 6** | Target: ~250 words (±5%) | Pause for review after drafting

## Prompt

Draft **Section 6: Key Open Questions / Learning Priorities** (~250 words) for the report on **{{TOPIC}}**.

### Audience

State explicitly who these learning priorities are for. Use the primary audience from PROJECT.md. For example: "These are learning priorities for the **strategy team** to explore in Phase 2" or "for **policy staff**". The audience determines the level of specificity and the kind of action implied by each priority.

### Structure

Present **3 learning priorities** for Phase 2 exploration. Each priority should have:

1. **Title** — A thematic label (e.g. "Models & methods for grassroots climate-truth work")

2. **2 sub-questions** (≤30 words each) — Specific, actionable questions the named audience could investigate within a realistic timeframe (weeks to months, not years)

3. **Why it matters** (≤40 words) — Connect to {{ORG}}'s **strategic pillars** (from PROJECT.md). Name the pillar(s) affected. Be practical — say what we'd lose by not investigating

### Typical Priority Themes

- **Models & methods** — What approaches can be adapted? How can they be embedded?
- **Partnerships & governance** — Who to ally with? What legal/regulatory issues to anticipate?
- **Inclusion & feedback loops** — How to reach excluded groups? How to measure impact?

## Style Rules

- Write as a colleague, not a consultant. First person plural ("we", "our").
- Plain, direct English. Short sentences (target under 15 words).
- Question format for sub-questions (start with "Which", "How", "What")
- "Why it matters" should be practical, not abstract — say what we'd lose by not investigating
- Connect priorities to findings from earlier sections
- Strict markdown list formatting (blank line before list, one item per line)
- Avoid consultant-speak: don't write "strategic alignment", "capability building", "knowledge gaps". Say what we need to find out and why. Before/after example: ❌ "Addressing capability gaps in participatory governance methodologies" → ✅ "We don't yet know how to run citizens' assemblies well. We need to learn from people who do."
- Define technical terms briefly on first use — assume the reader is smart but not a specialist
- **No meta-text:** Do not include word counts, drafting notes, or other artefacts in your output.
